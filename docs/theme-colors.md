# Theme Color Tokens

Color tokens for each theme preset. Layout decisions belong in `DESIGN.md` — this file documents colors only.

## Raycast

Based on the Raycast design system. All surface, text, border, accent, and interactive tokens.

| Token | Value | Role |
|-------|-------|------|
| `canvas` | `#07080a` | Page background |
| `surface` | `#0d0d0d` | Card / panel background |
| `surfaceElevated` | `#101111` | Elevated surface (hover, tertiary button) |
| `surfaceCard` | `#121212` | In-card surface, keycap fill |
| `buttonFg` | `#18191a` | In-card button fill |
| `ink` | `#f4f4f6` | Primary headline text |
| `body` | `#cdcdcd` | Default paragraph / link text |
| `charcoal` | `#d3d3d4` | Brightened body text |
| `mute` | `#9c9c9d` | Secondary / metadata text |
| `ash` | `#6a6b6c` | Disabled text |
| `stone` | `#434345` | Lowest-emphasis text |
| `onDark` | `#ffffff` | Interactive-state text |
| `onDarkMute` | `rgba(255,255,255,0.72)` | Translucent dark text |
| `hairline` | `#242728` | 1px card borders |
| `hairlineSoft` | `rgba(255,255,255,0.08)` | Faint overlay border |
| `hairlineStrong` | `rgba(255,255,255,0.16)` | Strong divider |
| `accentBlue` | `#57c1ff` | Info / link / accent |
| `accentBlueSoft` | `rgba(87,193,255,0.15)` | Blue background tint |
| `accentRed` | `#ff6161` | Destructive / error |
| `accentRedSoft` | `rgba(255,97,97,0.15)` | Red background tint |
| `accentGreen` | `#59d499` | Success |
| `accentGreenSoft` | `rgba(89,212,153,0.15)` | Green background tint |
| `accentYellow` | `#ffc533` | Warning |
| `accentYellowSoft` | `rgba(255,197,51,0.15)` | Yellow background tint |
| `primary` | `#ffffff` | Primary CTA background |
| `primaryPressed` | `#e8e8e8` | Primary CTA pressed state |
| `onPrimary` | `#000000` | Text on primary CTA |
